





--- REFLECTION ON UI/UX DECISIONS ---

The visual and interactive design of this portfolio prioritizes clarity, content hierarchy, and inclusive user experiences. By utilizing CSS custom properties, the color system seamlessly supports both light and dark themes while maintaining a strict WCAG AA contrast ratio (>4.5:1) for text legibility. A dark overlay was applied to the hero background image to guarantee high contrast and readability. Layouts are built using CSS Grid and Flexbox to ensure fluid responsiveness across mobile and desktop devices. Accessibility features—such as semantic HTML5 landmarks, explicit ARIA labels, and visible focus rings—were implemented so that all visitors, including screen reader and keyboard-only users, can easily navigate and evaluate the portfolio.
